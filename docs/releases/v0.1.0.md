## Included

- **Installable CLI:** Python 3.10+, `python -m pip install .`, `sgo tour`,
  `sgo validate`, `sgo --version` and module entry points. Legacy root scripts remain available.
- **Bring your own definitions:** `sgo byod examples/user-metrics.json` evaluates
  custom metric registries and expected-result cases. All supplied evidence is
  unverified; the output is a local read plan, not an executed query.
- **JSON Schema:** the bundled [registry schema](../../sgo/ontology.schema.json)
  validates input structure alongside semantic checks.
- **MIT license:** [LICENSE](../../LICENSE), copyright Michael Saleme.
- **Industry design guides (not deployed adapters):** energy, financial services, healthcare, manufacturing and
  retail/distribution, with synthetic readiness/calculation checks via
  `sgo industry-proof`. See [data-to-proof](../DATA-TO-PROOF.md).
- **Semantic-federation design guides (not deployed adapters):** [Data 360/Tableau architecture](../semantic-federation/ARCHITECTURE.md),
  six-platform mappings and MuleSoft contracts. These are not live adapters.
- **Inline demonstration:** [README demo](https://github.com/msaleme/salesforce-governed-ontology/blob/90c922d0fe3b73c72f45cd7a1a0c6906b128e58b/README.md#watch-the-terminal-demo) now embeds the GIF while
  preserving the original asciinema recording and local replay instructions.

## Install and try from the selected source commit

```sh
git clone https://github.com/msaleme/salesforce-governed-ontology.git
cd salesforce-governed-ontology
git checkout 90c922d0fe3b73c72f45cd7a1a0c6906b128e58b
python3 -m venv .venv
. .venv/bin/activate
python -m pip install .
sgo --version
sgo tour
sgo byod examples/user-metrics.json
python scripts/verify.py
```

Installation fetches jsonschema and build dependencies. The commands above run
locally without credentials or model calls. No PyPI availability is claimed.

## Version and evidence boundaries

This initial v0.1.0 replaces the unpublished 0.2.0 package placeholder; it is not
a downgrade of a published release. The earlier “0.1.0 design starter” changelog
entry is historical design work, not a package release.

Offline reference prototype, not an official Salesforce product. Built-in data
is synthetic; there is no live authorization, platform integration, independent
validation, production-readiness or measured performance claim.
