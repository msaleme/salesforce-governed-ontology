# Licensing decision packet (not a license grant)

## Recommendation

If the authorized owner clears public reuse, Apache License 2.0 is the recommended default for team adoption: an explicit patent grant and contribution terms are useful in organizational review. MIT is a shorter permissive alternative, but does not contain the same express patent grant. Neither choice establishes who owns this work.

## Decision required from the authorized owner

1. Confirm authority to license the repository, including any required employer/IP clearance and third-party review.
2. Select Apache-2.0, MIT, or retain the current no-license status.
3. Specify any approved copyright holder/notice; do not infer ownership from the GitHub account or research byline.

No license has been applied by this packet. [Current status](../LICENSE-STATUS.md) governs. Public visibility and a request to improve adoption are not themselves an ownership determination.

## Concrete application checklist after approval

- Add the selected license's unmodified canonical text as `LICENSE`.
- Replace the no-license notice with the authorized license decision and any approved attribution.
- Review contribution terms and update README evaluation/reuse wording consistently.
- Verify GitHub license detection and preserve the approval reference in the private decision record.

If clearance is unavailable, keep reuse explicitly blocked; do not market the repository as open source. A team can make its own evaluation decision, but this packet does not expand its legal rights.
